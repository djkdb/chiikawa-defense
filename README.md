# 치이카와 랜덤 디펜스 (비영리 팬 게임)

빌드 없는 정적 HTML + JS (Canvas 2D). `index.html` 을 열면 끝. 치이카와 © nagano · 공식과 관련 없음.

```
index.html          화면 틀 · CSS (v2 UI 키트는 「v2 UI 키트」 블록 한 곳 — --ui-* 값과 클래스만 바꾸면 그림을 입힐 수 있음)
js/table.js         숫자 전부 (난이도 · 칩 · 특성 · 보스 · 확률 표 · 행운 · 레시피 · 보상 카드 · 이자)
js/core.js          규칙 — 화면을 모름. node 에서도 그대로 돔 (tools/sim.js)
js/game.js          화면 · 입력 · 연출 · 덮개 화면
js/art.js           직접 그린 것(일반 괴물 · 길 · 바닥 · 투사체) + 캐릭터 시트 불러오기
js/mon.js           특성 괴물 · 보스 시트 프레임 불러오기 (assets/monsters/monsters.js)
js/sfx.js           효과음 — Web Audio 로 그 자리에서 합성 (잡음 「쉭」 없음)
assets/chars/       친구 8명 시트 프레임 (chars_manifest.py)
assets/monsters/    괴물 특성 5종 · 보스 4종 프레임 (tools/monsters_slice.py)
assets/tiles/       판 타일(풀밭 칸 · 흙길) · 소품(울타리 · 덤불 · 괴물 굴 …) (tools/tiles_slice.py)
assets/bg/          배경 맵(낮 들판 · 밤 숲) · 표지 (tools/tiles_slice.py)
js/tiles.js         타일로 판 바닥 · 위 여백 띠 굽기 (못 받으면 art.js 의 예전 바닥)
tools/sheets/       괴물 · 보스 · 타일 · 맵 원본 (사람이 만든 그림)
```

## 규칙 (v2)

- **소환 → 합성 → 강화**: 같은 친구 · 같은 등급 둘을 겹치면 한 등급 위 무작위 친구. 등급은 일반 · 희귀 · 영웅 · 전설 · **신화**. 합성은 전설까지.
- **난이도 4단** — 쉬움 · 보통은 처음부터, 바로 아래 난이도를 깨면 다음이 열림. 난이도별 최고 기록(웨이브 · 클리어 · 가장 빠른 클리어 · 무한 웨이브)은 이 브라우저 localStorage(`ck-defense-v1` 의 `d`).

  | 난이도 | 괴물 체력 | 길 위 한도 | 변수 칩 |
  |---|---|---|---|
  | 쉬움 | ×0.72 | 50 | 없음 |
  | 보통 | ×1 | 40 | 없음 |
  | 어려움 | ×1.18 | 40 | 1개 |
  | 지옥 | ×1.25 | 30 | 1~2개 |

  배수는 처음 정한 0.8 / 1 / 1.3 / 1.6 에서 sim 으로 줄였습니다(괴물 체력 자체를 뒤로 갈수록 크게 올렸기 때문 — 아래 「밸런스」).
- **변수 칩** (어려움 · 지옥, 판마다 무작위 · 시작 화면에 미리 보임): 바쁜 들판(이동 +25%) · 약초 들판(모든 괴물 초당 2% 회복) · 빈 지갑(시작 동전 −30%) · 살찐 괴물(체력 +30% · 동전 +30%) · 떼거리(괴물 +20%) · 대왕의 밤(보스 체력 +40%).
- **괴물 특성 5종** — 웨이브마다 1개(8웨이브부터 2개)를 골라 그 웨이브 괴물의 55% 에 붙임. 다음 웨이브 특성은 윗줄 「다음: …」 에 미리 보임.
  - 고속(2웨이브~): 1.6배 빠름 · 체력 −25% → 하치와레 둔화
  - 장갑(4~): 일반 공격 피해 절반 → 화상(시사) · 독(풍뎅이) · 관통(모몽가)은 그대로
  - 재생(6~): 초당 2% 회복 → 화상 · 독이 붙어 있으면 멈춤
  - 분열(8~): 쓰러지면 작은 젤리 둘 → 범위 공격
  - 부활(11~): 한 번은 체력 50% 로 일어남(쓰러진 동안은 안 맞음)
- **보스 기술** (5 · 10 · 15 · 20웨이브, 무한 모드는 순환): 침묵(친구 2칸 3초 봉인, 높은 등급부터) · 소환(졸개 5) · 회복(20%) · 셔플(칸 위 친구 자리를 마구 섞음). 기술 전엔 멈춰 서서 「준비」 프레임 + 「○○ 준비!」 + 경고음, 침묵은 노리는 칸이 보라색으로 깜빡임. 보스 막대에 다음 기술까지 남은 초.
- **소환 확률 업** — 동전으로 Lv0~5 (40 · 80 · 130 · 190 · 260). 표는 `table.js` 의 `odds.table`, 지금 확률은 판넬 막대 · 고른 친구가 없을 때 안내 칸 · 도감.
- **행운 소환** — 클로버(시작 2 · 보스마다 3)로 희귀 60% · 영웅 20% · 전설 10% 「확정」 에 도전. 실패할 때마다 그 칸 +5%, 성공하면 처음으로.
- **신화 레시피** — 서로 다른 전설 셋 → 신화 하나 (합성으로는 안 나옴).

  | 재료 (전설) | 신화 | 고유 스킬 |
  |---|---|---|
  | 치이카와 + 하치와레 + 우사기 | 신화 치이카와 | 다 같이 힘내! — 7번째마다 판 위 모든 괴물에게 2.2배 |
  | 우사기 + 시사 + 모몽가 | 신화 우사기 | 야하하하! — 8번째마다 주변 괴물 1.4초 멈춤 + 3배 |
  | 랏코 + 풍뎅이 + 치이카와 | 신화 랏코 | 별똥 베기 — 3번째마다 체력이 가장 많은 괴물에게 7배(보스 2배 더) |
  | 쿠리만쥬 + 하치와레 + 시사 | 신화 쿠리만쥬 | 들판 잔치 — 판 위 모든 친구 공속 +30% · 공격력 +20% |

  도감(「신화 레시피」 버튼)은 만들기 전엔 `???` — 판에 그 전설이 있으면 그 재료 이름만 보임. 한 번 만들면 이 브라우저에 「발견」 으로 남음.
  빠진 재료는 **남는 전설 + 클로버 1개**로 바꿀 수 있음(운에만 맡기지 않도록 — sim 에서 이게 없으면 신화가 거의 안 나왔음).
- **3택 보상** — 보스를 잡으면 카드 셋(확정 2 + 도박 1) 중 하나, 고르는 동안 시간이 멈춤. 확정: 동전 주머니 · 클로버 +2 · 영웅 초대장 · 힘내기 응원(공격력 +12%) · 소환 할인 · 울타리 보수(한도 +4). 도박: 반짝 상자(50% 전설) · 동전 뒤집기(두 배/절반) · 두근 강화(60% 등급 +1 / 40% 사라짐).
- **이자** — 웨이브가 넘어갈 때 지금 동전의 5% (최대 30).
- **같은 친구 시너지** — 판에 2명 이상 +10%, 4명 이상 +25% (고른 친구 설명에 보임).
- **무한 모드** — 20웨이브 클리어 화면의 「무한 모드로 계속」. 웨이브 시간 제한 없음, 보스 기술은 순환, 난이도별 무한 최고 웨이브 기록.
- **손맛** (보이기만 — 규칙 · 밸런스엔 영향 없음): 타격 멈칫(보스 치명 · 합성 · 보스 처치 · 신화 때 규칙 시간을 0.03~0.25초 세움) · 화면 흔들림 · 피해가 클수록 큰 숫자 ·
  처치하면 동전이 튀어 올랐다 윗줄 동전 칸으로 날아가 칸이 통 튐 · 1.5초 안에 이어 잡으면 콤보 숫자(10마다 소리) · 보스 등장 경고 띠 컷인(보스 그림 + 기술) ·
  새 특성이 처음 나오는 웨이브 컷인 · 합성/강화 때 등급 색 번쩍 + 「UP!」 + 레벨업 아르페지오.
- **색**: 크림 · 베이지를 쓰지 않음 — 페이지 바탕은 하늘색(낮 들판 · 밤 숲 맵), 종이 패널은 흰 종이(키트 패널을 흰색으로 바꿔 복사), 버튼은 노랑 · 하늘 · 분홍.

## 그림

- 친구 8명: `assets/chars/` (다른 작업 — `tools/chars_manifest.py`).
- 특성 괴물 · 보스: 사람이 만든 초록 바탕 시트(`tools/sheets/monsters.webp` · `bosses.webp`)를 `tools/monsters_slice.py` 로 잘라 `assets/monsters/`.
  크로마키는 「초록 정도」 gn = G − max(R,B) 로 키를 좁게(185 이상 투명, 130 이하 불투명) 잡아서 재생 괴물 잎(≈70) · 부활 쓰러짐 초록 유령(≈95~120) · 회복 보스 연두 빛을 지우지 않습니다.
  초록이 원래 없는 줄은 모든 픽셀의 초록 번짐을 깎고, 있는 줄(재생 · 회복 · 부활 쓰러짐)은 가장자리 3px 만 깎습니다.
  확인: `python3 tools/monsters_slice.py --board /tmp/mon.png` (어두운 · 밝은 바탕 확대 판).
- 시트 괴물은 오른쪽을 봐서 왼쪽 · 위로 갈 때 뒤집고, 보스 걷기는 왼쪽을 봐서 오른쪽 · 아래로 갈 때 뒤집음. 보스 「준비」 · 「쓰는 중」 프레임은 정면이라 안 뒤집음.
- 특성 없는 일반 괴물(꼬물이 · 단단이 · 졸개)은 예전처럼 `art.js` 가 그림.
- 판: `tools/sheets/tiles.webp` 를 같은 좁은 키로 잘라 괴물 길 = 흙길 타일(모서리 한 장을 뒤집어 네 방향), 친구 자리 = 풀밭 칸(대부분 보통 · 가끔 꽃 칸),
  고른 친구 = 노랑 칸, 침묵으로 봉인된 친구 · 침묵 예고 칸 = 보라 칸, 출발점 = 괴물 굴, 위 여백 = 울타리 · 덤불 · 꽃.
- 배경: `tools/sheets/maps.webp` 의 2×2 중 낮 들판(쉬움 · 보통) · 밤 숲(어려움 · 지옥, 판도 살짝 푸르게) · 표지(시작 화면 위). 왼쪽 아래(자격증 게임 것)는 안 씀.
- UI 키트: 공용 키트(`../_chiikawa_tools/ui/`, 자격증 게임과 같은 종이 · 나무 결 부품)를 `tools/ui_install.py` 가 `assets/ui/` 로 복사하고,
  index.html 의 `ui-kit:defense` 블록에 「기존 클래스 → 부품」 9-slice CSS 를 씀(버튼 · 알약 · 판넬 · 덮개 종이 · 난이도 · 보상 카드 · 레시피 칸 · 클로버/자물쇠 아이콘. 크림 버튼은 안 쓰고 패널은 흰 종이로 바꿔 복사).
  키트가 바뀌면 `python3 tools/ui_install.py` 만 다시.

알아낸 것
- 확률 업을 많이 사면 오히려 약해짐(강화가 밀리고, 높은 등급이 섞일수록 같은 친구 · 같은 등급 짝이 줄어듦). 봇은 2 · 6 · 10웨이브에 한 단계씩만 삼.
- 행운 소환(클로버)이 가장 큰 실력 차. 잘하는 봇과 느린 봇의 차이는 대부분 여기와 신화에서 남.
- 판 결과는 합성 운에 많이 좌우됨 — 같은 봇 · 같은 난이도에서도 씨앗마다 12~20웨이브로 갈림. 그래서 씨앗 40개로 봄.
